# Conservación básica

**Estado:** simulación académica; no aprobado para producción.  
**Audiencia:** comprador (índice de prueba).

Guardar el instrumento en un entorno estable y seguir las instrucciones del fabricante. Evitar sol directo, fuentes intensas de calor y humedad excesiva. Para limpieza, usar el material recomendado para el acabado del modelo; un producto adecuado para una superficie puede dañar otra. No aplicar solventes ni realizar ajustes eléctricos o estructurales basándose en una respuesta genérica. Si hay golpes, grietas o fallos eléctricos, describir el síntoma a soporte y solicitar revisión. Esta guía general no sustituye el manual del instrumento ni una evaluación técnica de un daño concreto.
